# Pocket Partner for Windows

Created and published by agammann.

1. Extract this entire ZIP to a folder.
2. Double-click **Play.cmd** to start. Keep the assets folder beside PocketPartner.exe.
3. Optional: double-click **Install.cmd** to install for your Windows account and add a desktop shortcut. No administrator account is needed.

Choose an egg and select **Set clock & hatch**. Your egg hatches in 30 active seconds. Feed, clean, play and train, then visit Battle.

Each evolution needs **72 awake, active hours** and battle XP. Sleep, pause, an unfocused window and a closed game stop the timer. Care never blocks evolution. First evolution needs 60 XP, the next 160; Caterpie needs 20 and 40. Wins earn 20–50 XP, completed losses earn 8, and retreating earns none.

Use Tackle to restore focus, a type burst for a strong attack, Guard to soften the next hit, and one berry per battle to recover HP. Partners heal after battles.

**Saves:** automatic in `%LOCALAPPDATA%\PocketPartner\partner.save`. Export from Game & saves; a backup is written beside the executable. Drop a `.save` file onto the game window to import, then confirm replacement. The browser game uses the same format.

**Uninstall:** remove `%LOCALAPPDATA%\PocketPartner\app` and the desktop shortcut. Your save is kept separately in the parent PocketPartner folder.
